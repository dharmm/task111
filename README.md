# E-Commerce Website

This is a single-page e-commerce website with product management and cart functionality. It includes a Flask backend and a React frontend.

## Features
- Add new products with name, price, and image.
- Delete existing products.
- Add products to the shopping cart.
- Manage cart items (add/remove).

## Technologies Used
- **Frontend:** React.js
- **Backend:** Flask (Python)
- **Database:** MySQL
